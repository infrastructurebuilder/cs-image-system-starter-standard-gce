# base_images/

Part of the shape of a configuration root, and **not read by the loader**:
the `base_images` collection is registered as base-only. Base images are the
OS builders in [`cfg/os-builders.yml`](../cfg/os-builders.yml); see
[CONFIGURATION.md section 11.1](https://github.com/infrastructurebuilder/cs-image-system-3/blob/v0.1.5/docs/CONFIGURATION.md#111-base_images).
